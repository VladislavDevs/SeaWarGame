# Морской бой (Sea War Game)

Консольная игра «Морской бой», написанная на Java. Проект представляет собой реализацию знаменитой игры, где игрок сражается против умного компьютерного соперника.

## Основные возможности
* **Игра против компьютера:** Поочередные ходы. При попадании ход остается у стрелявшего.
* **Умный ИИ:** Компьютер использует алгоритм «Охота/Добивание» (стреляет случайно, пока не попадет, затем уничтожает корабль).
* **Два игровых поля:** Вы видите свой флот и скрытое поле противника одновременно.
* **Генерация поля:** Случайная расстановка кораблей (с проверкой на касания и границы).
* **Удобная визуализация:** ASCII-графика, очистка консоли, подсветка последнего выстрела компьютера кружочками.

---

## Флаги
* **--random** -	Случайная расстановка кораблей (по умолчанию).
* **--static** -	Захардкоженная расстановка.
* **--seed <число>** -	Фиксирует генератор случайных чисел (например, --seed 12345).
* **--debug** -	Отладочный режим: показывает поле противника перед началом.
* **--demo** -	Демо-режим: ИИ играет сам с собой, чтобы посмотреть на алгоритм.
